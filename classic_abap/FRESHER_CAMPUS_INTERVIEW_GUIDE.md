## 🎯 2. What You Need to Know (Only the Core Basics!)

You do **NOT** need to memorize advanced topics like RAP, CDS Annotations, or Draft tables.
For campus interviews at Capgemini / HCL, interviewers only care that you know these **4 basic building blocks**:

### ① Data Dictionary (`SE11`)
* **What is a Transparent Table?**
  A table in the ABAP Dictionary that has a 1-to-1 physical table on the underlying database (with identical name and fields).
* **Delivery Class:** Set to `A` (Application table for master/transaction data).
* **Technical Settings:**
  * Data Class: `APPL0` (Master data) or `APPL1` (Transaction data).
  * Size Category: `0` (Expects 0 to 10,000 records).

### ② SAP Gateway (`SEGW`)
* **What is OData?**
  An open web protocol based on REST and HTTP (JSON format) used to get data into and out of SAP systems.
* **Key Components in SEGW:**
  * **Entity Type:** The blueprint/structure of an object (like structure `Employee` with fields `Empid`, `Name`, `Salary`).
  * **Entity Set:** A collection/table of entities (like `EmployeeSet`).
  * **MPC (Model Provider Class):** Holds metadata and schema definitions.
  * **DPC (Data Provider Class):** Holds data access and business logic.
* **Why do we write code in `DPC_EXT` instead of `DPC`?**
  * Because `DPC` is auto-generated by SAP. If you regenerate the service in SEGW, all code in `DPC` is wiped out.
  * `DPC_EXT` inherits from `DPC`, so our custom code is **never overwritten**.

### ③ The 5 CRUD Methods in `DPC_EXT` (Just Basic ABAP!)

Look at how simple the ABAP code really is:

| Method Name | HTTP Method | ABAP Code Inside (Plain English) |
| :--- | :---: | :--- |
| `EMPLOYEESET_GET_ENTITYSET` | `GET` | `SELECT * FROM zemply_mng_tab INTO TABLE et_entityset.` |
| `EMPLOYEESET_GET_ENTITY` | `GET` (by ID) | `SELECT SINGLE * FROM zemply_mng_tab WHERE empid = lv_empid.` |
| `EMPLOYEESET_CREATE_ENTITY` | `POST` | `io_data_provider->read_entry_data(...)` followed by `INSERT zemply_mng_tab FROM ls_emp.` |
| `EMPLOYEESET_UPDATE_ENTITY` | `PUT` | `io_data_provider->read_entry_data(...)` followed by `UPDATE zemply_mng_tab FROM ls_emp.` |
| `EMPLOYEESET_DELETE_ENTITY` | `DELETE` | `DELETE FROM zemply_mng_tab WHERE empid = lv_empid.` |

### ④ Testing Transactions
* **`/IWFND/MAINT_SERVICE`**: Transaction to register and activate the OData service.
* **`/IWFND/GW_CLIENT`**: Transaction to test the service URL directly inside SAP GUI without any external tools.

## 💬 3. Top 5 Questions Capgemini / HCL Interviewers Will Ask

### Q1: "What is `SY-SUBRC` and what does it mean?"
* **Answer:** `SY-SUBRC` is an ABAP system field that stores the return code of an operation. If `SY-SUBRC = 0`, the operation was successful. Any non-zero value (e.g., `4`) indicates failure or record not found.

### Q2: "What is the difference between `INSERT`, `UPDATE`, and `MODIFY` in ABAP?"
* **Answer:**
  * `INSERT`: Adds a new record. Fails if a record with the same primary key already exists.
  * `UPDATE`: Changes an existing record. Fails if the primary key does not exist.
  * `MODIFY`: Combined operation. If the record exists, it updates it; if not, it inserts it.

### Q3: "What HTTP methods map to CRUD operations in OData?"
* **Answer:**
  * **C**reate ➔ `POST`
  * **R**ead ➔ `GET`
  * **U**pdate ➔ `PUT` / `PATCH`
  * **D**elete ➔ `DELETE`

### Q4: "What is a Primary Key and did you use one in your table?"
* **Answer:**
  * Yes, in `ZEMPLY_MNG_TAB`, `MANDT` (Client) and `EMPID` (Employee ID) are the primary keys to ensure every employee record is uniquely identified.

### Q5: "What is a Foreign Key?"
* **Answer:**
  * A foreign key creates a relationship between two tables to maintain referential integrity. In `ZEMPLY_LEAVE_TAB`, the field `EMPID` refers to the `EMPID` in the master table `ZEMPLY_MNG_TAB`, ensuring a leave request cannot be created for a non-existent employee.
